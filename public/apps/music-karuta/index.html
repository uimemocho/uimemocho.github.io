遊び方

30秒で読める。

1「READY → GO」のあと、30秒プレビューが流れる。
2流れてる曲のジャケットをタップ。速いほど点が高い（最大+3）。
3相手も狙ってる。もたつくと Taken!、間違えると Miss! でしばらく動けない。
4時間切れは誰の得点にもならない。カードが尽きたら終了。
5ふたりで対戦は合言葉4桁を伝えるだけ。アカウントも設定もいらない。

音源について

Apple の公開APIを使ってるよ。

30秒プレビュー・ジャケット・曲情報は Apple / iTunes Store の iTunes Search API から取得しています。
これらはApple規約上「ストアへの誘導」が前提の素材です。本作では結果画面とコレクションから Apple Music の曲ページへ移動できます。
対戦の通信には、アカウント不要の公開MQTT中継を使っています。やり取りするのは曲IDと勝敗だけです。
